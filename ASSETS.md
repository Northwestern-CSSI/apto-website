# APTO asset review register

`content/apto/assets/` is the source of truth for site images. The content
builder creates byte-identical delivery copies under `public/apto/`; those
public copies should not be edited directly.

Inclusion in this repository does not transfer ownership or grant reuse rights
for third-party marks.

## Brand marks

- `content/apto/assets/nsf-logo.png` is the U.S. National Science Foundation
  mark. Its use must follow the NSF Brand Standards and Usage guidance.
- `content/apto/assets/partners/` contains participant marks sourced from
  participant websites or institutional brand resources. Confirm approved
  artwork, clear space, and usage with Aperture, Insilicom, Macrocosm,
  Northwestern University, and the University of Chicago before final launch.
  Source and approval metadata lives in each `participants/*.md` record.

## Site artwork

- `content/apto/assets/us-map.svg` is the project-page map base, sourced from a
  CC0 Wikimedia Commons U.S. states map. Attribution metadata and the source
  URL live in `content/apto/interface.md`.
- `content/apto/assets/og-apto.png` is the first-version social preview created
  for this site in the NSF-aligned navy, cyan, and gold palette.
- The remaining science-map, model, team, and network-art files are retained
  as source assets for earlier visual explorations. Review provenance,
  redistribution rights, privacy, and likeness where applicable before
  reusing them in a production page.

## Example interface data

The homepage widget uses clearly identified example values so an interface can
be evaluated before approved project data is connected. Those values are not
APTO findings or forecasts. Tool records describe intended research uses and
link to actual project resources only when a project supplies a URL.
