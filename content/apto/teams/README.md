# APTO team folders

Open your team's README for links to its current records and instructions for
updating them.

- [Northwestern University](northwestern/README.md)
- [University of Chicago](uchicago/README.md)
- [Apperture.AI](aperture/README.md)
- [Insilicom](insilicom/README.md)
- [Macrocosm](macrocosm/README.md)

All five teams use the same layout.

```text
teams/<team-id>/
├── README.md
├── organization.md
├── impact.md
├── projects/
├── people/
├── tools/
├── tool-collections/     Optional: tools presented together as one card
└── assets/
    ├── partners/         Logos
    ├── people/           Headshots, where available
    └── tools/            Team-specific figures, photos, and icons
```

Create image subfolders when you have files to add. The [shared asset
library](../assets/) holds images used across teams and program-wide artwork.
[NSF program contacts](../program-team/) have their own folder.

See the [APTO content guide](../README.md) for program-level text, convenings,
and build commands.
