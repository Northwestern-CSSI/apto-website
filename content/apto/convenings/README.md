# Annual convening records

Each annual convening is one Markdown file. Add a future year by copying
`2026.md`, changing its `id`, `year`, location, title, summary, discussion, and
image paths, then add the referenced images under
`content/apto/assets/convenings/<year>/`.

Every record must include exactly seven unique images. The first image is the
fixed opening photograph; the other six are shuffled in the browser each time
the gallery initializes. Include a full-cohort portrait first, followed by six
program or discussion scenes. The build copies those images to
`public/apto/convenings/` and uses the same content in Continuum and Atlas.
